# Fixture debito pubblico

Questi input sono sintetici e servono esclusivamente ai test offline. I codici
di serie e le dimensioni riproducono il contratto pubblico, mentre gli importi
non sono dati da pubblicare. I quattro ZIP BDS vengono costruiti in memoria dai
test con gli stessi quattro membri dell'export ufficiale; `eurostat.json` è un
sottoinsieme JSON-stat 2.0 minimo con ordine delle dimensioni deliberatamente
diverso da quello della query canonica.
