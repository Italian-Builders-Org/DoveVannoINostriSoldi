# Verifica UI batch 0 — home, Coesione, Consulenza

Head verificato: branch `codex/ui-navigation-pages`, build di produzione locale. Tema supportato: solo light; dark è `N/A` perché il prodotto non espone un tema scuro. Locale: italiano. Viewport: mobile 390×844, desktop 1280×1000. Ogni full-page è stata divisa in quattro fasce contigue che coprono il 100% dell'altezza; manifest e immagini restano artefatti locali in `.audit/quadrant-verification/`.

Le colonne sintetizzano tutti i criteri del contratto: comprensione in 5 secondi e priorità del dato (`5s/dato`), linguaggio e gerarchia in scala di grigi (`ling./gray`), leggibilità e semantica del colore (`leg./colore`), densità e ritmo 4/8 (`densità`), affordance/focus/tastiera (`azione/a11y`), fonti e metadati (`fonti`), reflow/overflow/runtime (`layout`). La full accessibility audit non è stata eseguita.
